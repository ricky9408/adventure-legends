# Magma chapter design packet

Developer-only; all creature/puzzle/plot spoilers stay out of player previews. No runtime content enabled, no game source modified, no downloads/install/publish operations.

- MAGMA_CHAPTER_BRIEF.md: connected region, invented cultural/ecological identity, main story, six optional side stories, puzzles, discoveries, boss and safety
- MAGMA_CREATURE_CARDS.md:24 individual form/animation/field/command/evolution specifications
- MAGMA_COLLECTION_SAFETY.md: newly required terminal-opportunity admission, all-choice-order proof and grandfathered legacy limitation
- terminal_admission.py / test_terminal_admission.py: capacity/matching model and adversarial tests
- MAGMA_IMPLEMENTATION_CONTRACT.md: exact revision, trial, source, quest, event, gear and hardware boundaries
- magma_allocation.json: authoritative proposed allocation and source hashes; exact full128 milestone partition preserved
- identity-lock.snapshot.json: all128 unchanged identity tuples
- validate_design.py: read-only design checks, complete abstract puzzle-state exploration and constructive34-individual collection witness plus exhaustive all-choice-order capacity proof
- test_design.py and test_terminal_admission.py:66 combined good/adversarial design checks
- validation_report.json and unittest_report.txt: checked results, with native/runtime limitations explicitly stated
- build_design.py: deterministic design-artifact emitter; it reads Southern source and writes only this directory

Run from this directory:

    python3 validate_design.py --report validation_report.json
    python3 -m unittest -v test_design.py test_terminal_admission.py

The accepted allocation is24 forms in nine families, not12. Third tiers and branch targets stay design-only until architecture and full native gates pass. The full chapter remains the intended milestone; no partial runtime slice is approved here.

Five optional global quests plus one discovery-backed journal commission provide six optional stories without stealing the next region's IDs. This is eight global quests total including teaching/main tasks.

Passing checks mean the design is internally consistent. They do not mean a playable room, accepted art, implemented save migration, native command handler, measured frame budget or obtainable form exists. The eventual implementation must rebase these proposals on the accepted Southern source and independently verify the final ROM.

Revision2 closes the unrestricted repeat-base capacity softlock prospectively: every admitted gameplay mutation preserves at least one free slot per missing final terminal opportunity. It reserves72 opportunities and allows88 excess copies. Pre-existing legal over-budget collections remain unchanged and loadable; admission alone cannot make them globally completable. This is a design proof and a required new implementation gate, not a runtime fix.
