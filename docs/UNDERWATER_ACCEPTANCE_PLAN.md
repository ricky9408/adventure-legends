# Underwater acceptance gates (development)

The current chapter is **not delivered**. Data/core enable89 forms, but only a
single passing final-ROM acquisition run, independent cold replay and native
combat review can turn that into a release claim. Earlier A/B diagnostic runs
remain separate evidence with their original failures.

## Required final evidence

- Clean reproducible ROM, exact ELF/symbol/source pairing and generator roundtrip
- Controller-only old34/65→50 individuals/89 histories; all46 quests and37 gear
- Independent old minimal10→12 main route, no optional training or armor needed
- All21 directed exits, reversible mechanisms, resets and deliberate return paths
- All24 commands, usable ordinary-enemy counterplay, visible field-target overlap,
  same-individual trials/evolutions,8 repeat recruitment demonstrations
- Same-ROM storage/quick-selector, frozen modal inputs, cooldown/identity isolation,
  death/retry, exact cold saves and historical revision1–5 import policies
- Every measured active-play, cast, dialogue, evolution, transition and incremental
  save window advances game state and displayed bitmap once per GBA frame
- Cold Continue is explicitly a bounded blocking decode before active play, not
  a59.73Hz gameplay claim; retain its loading trace and frame-counter reset
- Native stills across all8 areas and24 forms, original bright art and full viewport
- Independent source review, host strict/sanitizer/fault tests and observed stack
  overwrite extent (neither exhaustive maximum-SP nor physical hardware proof)

## Known development blockers being fixed

A/B evidence revealed frame hitches in cold/evolving UI, older Southern combat,
Southern rest and surface return, plus several new moving powers. The first
renderer/collision optimization fixes old combat/storage without changing30
measured modal bitmaps. Staged exact-state validation and deferred writer resume
address mixed heavy-update/cold-redraw frames. New power optimization is pending
native recheck. Command77 needs a genuinely traversable ordinary-enemy window;
visible field targets must not demand center-pixel alignment.

A segmented B debug route did obtain all89 histories/50 real individuals, but
it includes earlier failed attempts and precise-controller field workarounds.
It supports diagnostics only, not final acquisition acceptance.

## Release limits and files

No physical cartridge or alternative-emulator claim. Existing original PSG audio
only; no orchestral/VoiSona integration is present. Save wire remains5, content
revision6; back up SRAM, retain matching ROM/save basename and avoid downgrades.
Final player media will show ordinary town exploration without puzzle solutions,
rare encounters or the ending. Source-only publication follows the tested freeze.
