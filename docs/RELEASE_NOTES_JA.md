# Adventure Legends: Emberbond 水中の町アップデート

動作確認を終えた水中の町アップデート（ビルドK）の案内です。ゲーム全体は引き続き開発中です。

明るい水中の町と、その先の記録庫へ続く旅路を追加しました。
住人の話を聞き、音や浮き沈みの仕掛けを仲間と試しながら歩いてみてください。

- 新しい８つの場所と８件のお願い
- ８つの仲間の家族、24の姿、16の任意の成長の道
- 24の新しい技と６つの装備の選択肢
- 何度でも試せる仕掛けと、しおりの手がかり
- これまでの武器、装備、仲間の切り替え、選べる進化を引き続き使用

山の街の本筋のお願いを終えて報告したら、街の貝の昇降機を探してみてください。
水中でもいつもの操作で動けます。酸素の残量や必須の呼吸用装備はありません。

Lを押しながら十字キーで仲間を選び、Lを離すと切り替わります。
選択中はBで取り消せます。STARTのしおりで連れていく４体を変更できます。
Rの直後に方向の案内が出たら、その方向を新しく押してください。
詳しい操作は [遊び方](PLAY_JA.md) にあります。

この版には、全体で89の姿、38の家族、54の場所、46件のお願い、37種類の装備を実装しています。
姿の数には進化後を含みます。128の姿と残りの旅に向けて、ゲーム全体の開発は続いています。
完成版や想定プレイ時間の発表ではありません。

更新前に `.sav` をバックアップしてください。ROMとセーブの名前は拡張子以外を同じにします。
以前の公開版の記録（形式２〜４、形式５の内容版１〜５）を、形式５・内容版６へ引き継げます。
更新後の記録を古いROMで使わないでください。戻す場合は更新前のバックアップを使います。
「つづきから」の読み込みは、この版の確認した範囲で最大52ハードウェアフレーム、約0.9秒です。

音楽と効果音は従来のオリジナルPSG音源です。新しいオーケストラ音源は含みません。
実機での確認はまだ行っていません。
