# 装備と宝物の更新

- 装備の数値と矢印を大きくし、選ぶ前に効果を比べやすくしました
- 仲間の技の待ち時間、武器の距離、敵をひるませる効果も見られます
- 大きな戦いの後に、冒険を支える宝物とGを受け取れます
- 前の版で進めた冒険の未受け取りの宝は、最初の里の道具屋で確認できます
- 持っている仲間が多いときの、記録開始による動きの引っかかりを抑えました

装備は左右で部位、上下で品物を選び、Aで決定、Bで戻ります。宝物は装備しなくても働きます。

更新前に通常の .sav をコピーして残してください。新ROMとセーブを同じ名前にして「つづきから」。内容版11に更新されたセーブを古いROMへ戻すときは、更新前のバックアップを使ってください。
