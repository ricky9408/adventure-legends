# Adventure Legends: Emberbond 火山の町アップデート

明るい段々の町と、湯気の向こうへ続く新しい旅路を追加しました。
住人の話を聞き、仲間と仕掛けを試しながら、寄り道も楽しんでください。

- 新しい町、フィールド、工房、地下の探索エリア
- 新しい仲間と、その個体の成長を選べる進化
- 武器や装備の新しい選択肢、住人からのお願い
- 仲間が増えたときの切り替え、保存、メニューの動作を改善

Lを押しながら十字キーで仲間を選び、Lを離すと切り替わります。
選択中はBで取り消せます。STARTの手帳で連れていく4体を変更できます。

南の島での進行を済ませたら、町の新しい案内を探してみてください。
詳しい操作は [遊び方](PLAY_JA.md) にあります。

更新前に `.sav` をバックアップしてください。エミュレーターで新しいROMと
同じ名前のセーブを使用すれば、これまでの記録を引き継げます。
新しい記録を古いROMへ戻して使うことはおすすめしません。

この版の音楽は従来のオリジナルPSG音源です。ゲーム全体は開発を続けています。
